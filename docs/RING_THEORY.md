# Finite commutative rings, ideals, and CRT

The `calc.rings` module gives an exact, bounded teaching model for the
commutative residue ring \(R=\mathbb Z/n\mathbb Z\). It does **not** implement
arbitrary finite rings, noncommutative rings, integral domains, Noetherian
theory, or algorithmic ideal theory over polynomial rings.

The supplied modulus is a strict Python integer with \(2\le n\le4096\).
Elements are represented by canonical residues \(0,\ldots,n-1\), and all
operations are exact integer operations. In particular, a residue may have a
multiplicative inverse only when \(\gcd(a,n)=1\). A *nonzero* residue is a
zero divisor exactly when its gcd with \(n\) exceeds one.

```python
from calc.rings import ResidueRing, chinese_remainder

r = ResidueRing(12)
assert r.add(11, 5) == 4
assert r.multiply(4, 6) == 0     # nonzero zero divisors
assert r.inverse(5) == 5

i = r.ideal(4)
assert i.elements() == (0, 4, 8)
assert i.quotient_order == 4
assert i.quotient_class(11) == 3

assert r.annihilator(4).elements() == (0, 3, 6, 9)
assert chinese_remainder((2, 3, 2), (3, 5, 7)) == (23, 105)
```

## Principal ideals and quotient operations

Every ideal of \(\mathbb Z/n\mathbb Z\) is generated by a divisor \(d\mid n\).
More explicitly,

\[
 (a_1,\dots,a_k)=(d),\qquad d=\gcd(n,a_1,\dots,a_k).
\]

The ideal contains the residues divisible by \(d\) and has \(n/d\)
elements. The quotient \(R/(d)\) has \(d\) classes, canonically identified
with \(\mathbb Z/d\mathbb Z\). `PrincipalIdeal.quotient_class` returns this
integer class, and `quotient_add` / `quotient_multiply` implement its induced
ring operations. The *whole* ideal \((1)\) has a single quotient class: this
is the zero ring. The code supports the one-class quotient but does not
instantiate `ResidueRing(1)` as an ambient ring, because conventions about
admitting the zero ring vary.

For ideals corresponding to divisors \(d,e\mid n\):

\[
 (d)+(e)=(\gcd(d,e)),\quad
 (d)\cap(e)=(\operatorname{lcm}(d,e)),\quad
 (d)(e)=(\gcd(n,de)).
\]

The annihilator is likewise principal:

\[
 \operatorname{Ann}(a)=\{x:ax\equiv0\pmod n\}
 =\left(\frac{n}{\gcd(n,a)}\right).
\]

The public ideal API exposes containment, element enumeration, intersection,
sum, product, annihilator, and quotient classes. It does not enumerate
arbitrary presentations of ring homomorphisms or classify nonprincipal
ideals in other rings.

## Chinese remainder theorem

`chinese_remainder(residues, moduli)` requires *pairwise-coprime* moduli and
returns the canonical solution \(0\le x<\prod m_i\) alongside the product.
It rejects empty or mismatched input, noncoprime moduli, more than 16
congruences, individual moduli greater than 4096, or a modulus product
exceeding \(2^{63}-1\). Negative residue representatives are normalized.
It deliberately does not attempt the more general compatibility criterion
for noncoprime moduli.

## Verification and resource limits

- `tests/test_rings.py` checks the ring axioms exhaustively for moduli 2–13.
- A seeded, independent additive-span oracle checks 100 small generated ideals;
  another 80 cases enumerate annihilators by direct multiplication.
- Quotient operations are tested against 70 independently selected residue
  classes; CRT is checked for every pair of congruence residues over small
  coprime moduli, including negatives and errors.
- Ideal generator count is at most 128; exponentiation is capped at one
  million; all numerical work uses bounded exact integers without floats.

These checks are executable examples and finite-domain witnesses, not formal
proof of every ring-theoretic assertion or external peer review.
